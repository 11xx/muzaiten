# Content, evidence, and authority

Git transports this public packet and the executor's source commits. Its
files are explicitly curated inputs; the checksum manifest detects drift.
The return report and receipt describe execution claims for the local lead to
check. They do not grant approval or integration authority.

Arc's change export/import exchanges versioned ledger events and references
to Git objects between Arc-capable stores. Its journal export/import exchanges
selected artifact bodies and their events, including referenced artifacts.
These bundles can contain private provenance and are suitable for explicit
replica exchange. A raw bundle is not the public task description in this
packet. Git transport also does not synchronize the external journal.

The local journal maps each curated task to its originating artifact and
retains the private session and delivery references. The cloud worker does
not need Arc installed, a replica pairing, or integration authority for this
series. The local lead checks the returned branch, records its evidence and
attribution in Arc, and controls signing, review, integration, and publication.

An Arc packet-assembly helper can own deterministic content selection and
checksums. Network transport and cloud process dispatch belong to transport
or delegation tools; pinned tool/config realization belongs to environment
tools. Public projection requires explicit curated inputs. Automatic
redaction is not proof that arbitrary journal content is publishable.

A packet-assembly trial is separate work in the Arc repository. It must not
modify Arc from a muzaiten task, expand this series' scope, or alter bundle
import, review, replica authority, or integration rules.
